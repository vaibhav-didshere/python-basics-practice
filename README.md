# python-basics-practice

📌 Overview

This repository contains basic Python programs and problem-solving examples. It is designed to build a strong foundation in Python programming through hands-on practice.

🧠 Topics Covered
- Variables
- Loops
- Conditions
- Functions

💻 Problems Solved
- Palindrome
- Prime number
- Factorial
- Calculator
- Number Guessing Game 

🎮 Number Guessing Game
A simple game where:

- The computer generates a random number
- The user tries to guess it
- Feedback is given (Too High / Too Low) until correct

▶️ How to Run

python filename.py
